**Support Ticket Management System**

A web application developed to manage technical support requests, customers, internal users, ticket tracking and notifications.

Sistema web para gestionar solicitudes de soporte técnico, clientes, usuarios internos, seguimiento de tickets y notificaciones.

**Stack:** React · Node.js · PostgreSQL · Supabase

- Ticket management and tracking.
- Role-based access control.
- Evidence storage.
- Email notifications and password recovery.
